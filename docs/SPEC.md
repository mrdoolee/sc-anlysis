# 성적 추세 분석 웹앱 — 확정 스펙

## 1. 목적
중학교 교사가 학급 학생의 성적 **추세**를 원점수 중심으로, 필요 시 표준화 점수(z, T)로 분석한다.
모든 처리는 브라우저 안에서만 이루어지며, 성적·이름·학번·분석 결과는 기기 밖으로 나가지 않는다.

## 3. 입력 형식 (자동 감지, 헤더 이름 기반)
- **고사(가로형)**: `성명` + `합계`가 있는 헤더 행. 헤더 다음 행의 `만점:N`. 상단 텍스트에서 `(\d{4})학년도`, `(\d)학기`, `(\d)학년`, `(\d+)반`, `(\d+)회고사` 추출.
  학생 행: 첫 열 숫자 + 성명 존재. 요약 행: 첫 열(공백 제거)이 `응시생수|총점|평균|학년응시생수|학년총점|학년평균`.
  성명 열과 번호 열 사이의 숫자 열 = 학번.
- **학기 성적(세로형)**: 첫 열 `번호` 헤더가 반복되며 헤더마다 열 위치를 다시 읽는다. `원점수/과목평균` 열이 없는 섹션(체육·예술, 교양교과)은 수치 분석 제외.
  번호·성명·학년·학기는 forward-fill. `"34/69.1"` → 원점수 34, 과목평균 69.1. `수강자수` → 응시자 수.
  학년·학기별로 시점을 분리하며, 수치 점수가 하나도 없는 학기(P만)는 시점으로 만들지 않고 알림만 남긴다.
- 시험 유형: `exam`(고사) / `semester`(학기종합). 둘이 같이 표시되면 "측정 기준이 다를 수 있음" 주석.

## 4. 계산 정의
- z = (x − μ)/σ, T = 50 + 10z. μ, σ = 해당 시점·항목에 점수가 있는 학급 학생, 모표준편차(ddof=0).
  σ = 0 또는 n < 5이면 z 없음(사유 표시). 학년 σ는 사용자가 입력했을 때만 z(학년) = (x − 학년평균)/σ학년.
- 학년평균 대비 편차 = x − 학년평균.
- 석차: 경쟁 순위(동점 동순위, 다음 순위 건너뜀). 백분위 PR = (낮은 학생 수 + 0.5 × 동점 학생 수(본인 포함)) / n × 100.
- 공통 과목 평균: 선택한 시점 모두에 존재하는 과목만 평균. 학생이 공통 과목 중 하나라도 결측이면 그 시점 평균은 결측.
- 교과군: 묶음 내 해당 시점에 존재하는 과목의 평균(시점마다 구성이 다를 수 있음 → 표시).
- 추세: Δ = 마지막 − 첫 시점, 기울기 = 시점 순번(0,1,2…)에 대한 최소제곱 기울기(시점 3개 이상), 변동성 = z의 모표준편차.
  라벨: Δz ≥ +0.5 상승, ≤ −0.5 하락, 그 외 유지(설정 변경 가능).
- 주의 학생: 최근 Δz ≤ −1.0, 2회 연속 하락, 최근 과목 z ≤ −1.5 (설정 변경 가능).
- 성취도 환산: A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, E < 60 (만점 대비 %, 설정 변경 가능).
- 학기종합↔고사 격차: 같은 학년·학기의 학기 점수 − 그 학기 고사 점수 평균.
- 무결성: 학생 합계/평균, 학급 총점/평균을 재계산해 허용오차 0.05 초과 시 경고.
- 내부 계산은 원값, 표시는 소수 첫째 자리.

## 5. 시나리오 (시점 선택 프리셋)
S1 학년 전환(직전 학년 학기 성적 + 현재 학년 첫 고사), S2 학년 내 고사 누계, S3 전체 이력, S4 두 시점 A↔B, 사용자 지정.
분석 탭: 학생 개인(S5 과목 프로파일, S6 석차·백분위 포함) / 학급 개관(S7) / 주의 학생(S8) / 학기종합↔고사(S9). 단위 토글 과목 ↔ 교과군(S10).

## 6. 출력
- HTML: 자체 포함 단일 파일(인라인 CSS + SVG, 스크립트 없음, CSP `default-src 'none'; style-src 'unsafe-inline'; img-src data:`).
- PDF: 인쇄 CSS(A4, 여백 15mm, 학생별 쪽 나눔) + 브라우저 인쇄 → "PDF로 저장".
- 범위: 학생 1명 / 선택 학생 / 학급 전체(학급 요약 + 학생별 1장) / 학급 요약. 익명화 옵션.
- 학생 리포트: 학생·학부모 전달용 A4 1장(인쇄 영역 180×266mm 고정). 원점수, 학급·학년 평균, 변화, 쉬운 설명(최대 5문장), 선생님 의견 칸. z·T·석차·백분위·주의 신호는 넣지 않음. 표는 첫 시험 + 최근 5개 시험까지.
