# 몇점 분석기: 성적 분석 도우미(중학교 학급 담임용)

중학교 교사가 학급 학생의 성적 **추세**를 분석하는 웹앱입니다. 원점수를 기준으로 보고, 필요하면 표준화 점수(z·T)로 비교합니다.
모든 처리는 브라우저 안에서만 이루어집니다. 성적·이름·학번과 분석 결과는 기기 밖으로 전송되지 않습니다.

## 실행

### 그냥 쓰기 (설치 불필요)
1. `dist/index.html`을 더블클릭해 Edge 또는 Chrome으로 엽니다(인터넷 연결 불필요).
2. 성적 xlsx 파일을 끌어다 놓습니다.

`dist/index.html`은 JS·CSS가 모두 들어 있는 단일 파일이라 USB 등으로 옮겨도 그대로 동작합니다.

### 개발
```bash
npm install
npm run dev          # http://127.0.0.1:5173 (개발 서버, 이 컴퓨터에서만 접속)
npm run build        # dist/index.html 단일 파일 생성 + CSP 적용
npm run verify       # 타입검사 → 단위 테스트 → 빌드 → 개인정보 점검 → E2E
npm run fake-data    # 시연용 가짜 xlsx를 fake_data/에 생성
```
E2E는 시스템에 설치된 Edge를 씁니다(브라우저를 내려받지 않음). Chrome을 쓰려면 `E2E_CHANNEL=chrome npm run e2e`.

## 사용 흐름
1. **불러오기**: 고사 일람표(가로형)와 교과학습발달상황(세로형) xlsx를 여러 개 함께 불러옵니다. 형식은 자동으로 감지합니다.
   - 고사 일람표: [나이스] - [학급담임] - [정기시험조회/통계] - [정기시험조회] - [학급별일람표조회-전체교과목] - [저장] 버튼, XLS data
   - 교과학습발달상황: [나이스] - [학급담임] - [학교생활기록부] - [학생부 항목별 조회] - [교과학습발달상황-교과학습발달상황] - [저장] 버튼, XLS data
2. **데이터 확인**
   - 시점: 시점마다 한 줄 상자로 보이며, 펼쳐서 이름·유형·학년/학기/회차를 수정하고 ▲▼로 순서를 바꿉니다. 필요 없는 시점(예: 학기 성적 파일 안의 원하지 않는 학년·학기)은 '제외'로 분석에서 빼고, '다시 포함'으로 되돌립니다.
   - 과목 매핑: 예) 사회 → 역사. 같은 교과의 후보를 자동으로 제안합니다.
   - 학생 매칭: 결측과 번호 불일치를 표시하고, 필요하면 병합합니다.
   - 무결성 점검: 파일 합계·평균과 재계산 값을 대조합니다.
   - 학년 표준편차 입력(선택).
3. **대시보드**: 위에서 아래로 차례대로 고릅니다.
   - ① **시점 선택**: 비교할 시험·학기 버튼(처음엔 모두 선택)
   - ② **분석 과목**: 단위(과목/교과군), 점수 기준(원점수·z·T), 중심 과목, 그래프에 표시할 과목
   - ③ **분석 대상**: 학생 분석(학생 선택) / 학급 분석 / 주의 학생
   - 학생 분석의 '과목별 추이(원점수)'와 '표준화 추이(z점수)'는 늘 보이며, 누르면 모달로 크게 봅니다. 나머지 차트는 기본 접혀 있습니다.
   - **학급 석차·백분위는 '석차 보기'를 눌러야 보입니다.** 학생을 바꾸거나 다른 화면으로 가면 다시 가려집니다(상담 중 노출 방지).
   - 학급 분석의 학생별 표는 머리글을 눌러 정렬합니다.
   - **✦ AI 프롬프트**: 지금 보는 학생 또는 학급의 성적을 익명 데이터(이름·학번·번호·반·학교·선생님 의견 없음, 석차 없음)로 정리한 LLM 분석 요청문을 만듭니다. 학급 프롬프트의 학생은 무작위 순서의 익명 코드(S01…)입니다. 앱은 보내지 않으며, 교사가 확인 후 '복사하기'로 직접 붙여 넣습니다.
4. **내보내기**: HTML 파일 또는 인쇄(PDF로 저장)로 내보냅니다. 범위는 학생 1명, 선택 학생, 학급 전체, 학급 요약 중 고르며, 익명화 옵션이 있습니다. 아래에서 A4 미리보기를 볼 수 있습니다.
   - 선생님 의견 칸을 넣거나 뺄 수 있고, 학생별 의견을 이 화면에서 입력합니다(최대 250자, 비우면 손글씨용 빈 칸). 의견은 메모리에만 있고 새로고침하면 사라집니다.

왼쪽 메뉴 맨 위 **개인정보보호** 상자의 '개인정보보호 안내 보기'에서 데이터 처리 방식을, 메뉴 아래 **사용 설명서** 버튼에서 사용법을 볼 수 있습니다.

### 학생·학부모용 리포트 (A4 1장)
학생 리포트는 학생·학부모에게 전달할 내용만 담아 **A4 한 장**에 맞춥니다.
- 머리글: 학생 이름, 학급·번호, 비교 기간, 발행일
- 핵심 숫자 4개: 최근 평균, 처음 대비 변화, 학년 평균과 비교, 흐름(상승·유지·하락)
- 그래프 3개: 공통 과목 평균 변화(학생·학급·학년 평균), 표준화 추이(z점수, 0 = 반 평균), 최근 시험 과목별 점수 vs 학년 평균
- 시험별 점수표(첫 시험 + 최근 5개 시험까지)
- 쉬운 설명 최대 5문장, 선생님 의견(입력하거나 손글씨용 빈 칸, 또는 빼기)

석차·백분위·성취도·T점수·주의 신호는 넣지 않습니다. 교사용 상세 분석은 대시보드와 '학급 요약' 리포트에서 봅니다.

## 화면 디자인
왼쪽 단계 내비게이션, 상단 요약 막대, 카드형 필터·지표·차트로 구성한 대시보드입니다. 디자인 토큰은 [src/report/report.css](src/report/report.css)의 `:root`에 있습니다(Pretendard, #1D4ED8 기본색, #38BDF8 강조색, 카드 반경 14px).
Pretendard 글꼴(OFL-1.1)은 빌드 파일 안에 내장되어 웹 폰트 요청이 없습니다. 그래서 `dist/index.html`이 약 2.8MB입니다. 내보낸 HTML에는 글꼴을 넣지 않으며, 설치된 Pretendard가 없으면 맑은 고딕으로 표시됩니다.

## 분석 시나리오
시나리오 드롭다운은 없앴습니다. 대시보드의 **비교할 시점** 버튼으로 같은 비교를 직접 고릅니다(처음엔 모든 시점 선택).

| 코드 | 내용 | 고르는 방법 |
|---|---|---|
| S1 | 학년 전환: 직전 학년 학기 성적 + 현재 학년 첫 고사 | 해당 시점 버튼만 선택 |
| S2 | 학년 내 고사 누계 | 그 학년 고사만 선택 |
| S3 | 전체 이력 | 모두 선택(기본값) |
| S4 | 임의의 두 시점 A↔B, 전회 대비 변화 | 두 시점만 선택, 학생 탭 Δ 막대 |
| S5 | 과목 강약 프로파일(레이더, 과목×시점 z 히트맵) | 학생 탭 |
| S6 | 학급 내 석차·백분위 추이 | 학생 탭('석차 보기'를 누른 경우만) |
| S7 | 학급 개관(평균 추이, 상자그림, 히스토그램, 히트맵, 산점도, 추세 분포) | 학급 탭 |
| S8 | 주의 학생 감지 | 주의 학생 탭 |
| S10 | 교과군 단위 비교 | 단위: 교과군 |

학년은 고정되어 있지 않으며, 1~3학년 어떤 조합이든 같은 규칙으로 동작합니다.
계산 정의는 [docs/SPEC.md](docs/SPEC.md) §4와 화면·리포트 하단 각주에 있습니다.

## 가정
- 입력은 xlsx이고 첫 번째 시트만 읽습니다. `.xls`는 Excel에서 `.xlsx`로 저장한 뒤 불러와야 합니다.
- **고사 파일**
  - 제목 행의 `학년도·학기·학년·반·N회고사`로 시점을 정합니다. 읽지 못하면 데이터 확인 화면에서 입력합니다.
  - 회차는 학년도 안의 누적 번호로 봅니다.
  - 헤더의 `번호`와 `성명` 사이에 있는 숫자 열을 학번으로 봅니다.
- **학기 성적 파일**
  - `원점수/과목평균`이 없는 섹션(체육·예술, 교양교과)과 점수가 없는 학기(성취도 P만 있음)는 수치 분석에서 제외합니다.
  - 만점은 100으로 가정합니다.
  - `과목평균`은 학년 평균, `수강자수`는 응시 인원으로 봅니다.
- 학생은 이름(공백 제거)으로 파일 간에 연결합니다. 한 시점 안에 같은 이름이 있으면 `이름#번호`로 구분합니다.
- 빈 점수는 0점이 아니라 결측입니다. 공통 과목 평균은 공통 과목 중 하나라도 결측이면 결측으로 둡니다.
- 표준화 기준은 학급(모표준편차)입니다. 학년 표준편차는 파일에 없어 사용자가 입력했을 때만 z(학년)을 계산합니다.
- 응시 인원이 5명 미만이거나 표준편차가 0이면 z를 계산하지 않습니다.
- 성취도 환산 기본값은 A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60입니다(설정에서 변경). 샘플 파일의 성취도와 일치함을 확인했습니다.
- 추세 라벨 기준은 |Δz| ≥ 0.5이고, 주의 기준은 최근 Δz ≤ −1.0, 2회 연속 하락, 또는 과목 z ≤ −1.5입니다(설정에서 변경).
- 학기 성적과 지필고사는 측정 기준이 다를 수 있습니다. 두 유형이 섞이면 화면과 리포트에 주석을 표시합니다.
- PDF는 브라우저 인쇄의 'PDF로 저장'으로 만듭니다. 시스템 한글 글꼴(맑은 고딕 등)을 쓰므로 별도 폰트 파일이 필요 없습니다.

## 한계
- 학생 리포트는 A4 1장에 고정되어 있어, 시점이 6개를 넘으면 표에는 첫 시험과 최근 5개만 싣습니다. 그래프는 모든 시점을 보여 줍니다.
- 인쇄 배율을 100%가 아닌 값으로 바꾸면 1장에 맞지 않을 수 있습니다.
- 학년 석차와 학년 표준편차는 원자료에 없어 계산하지 않습니다.
- 학생 매칭은 이름 기준입니다. 개명이나 이름 표기 차이는 '병합'으로 직접 연결해야 합니다.
- 데이터는 저장되지 않으므로 새로고침하면 파일을 다시 불러와야 합니다(개인정보 보호를 위한 의도된 동작).
